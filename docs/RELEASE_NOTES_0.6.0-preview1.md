# CryptoPro Cleanup 0.6.0-preview1

Локально проверенный кандидат предварительного релиза.

## Что нового

- Modern-интерфейс с понятными действиями на главной странице: сохранить данные, выбрать сертификаты или открыть данные другого диска.
- Отдельное сохранение лицензий, открытых сертификатов и отчёта без запуска удаления.
- Закреплённая подсказка следующего шага и улучшенная адаптивность окна.
- Подписанная текстом компактная навигация и исправления для маленьких окон Legacy.
- Исправлена проверка версии помощника продолжения после перезагрузки.
- Скриншоты удалены из репозитория и документации.

## Редакции

- **Modern** — Windows 10/11 x64.
- **Legacy** — Windows 7 SP1 и новее, x86/x64.

## Проверки

Проверены сборки MSVC v143, native-тесты Win32/x64, безопасный интеграционный сценарий резервного копирования, Modern UI smoke и Legacy UI smoke на малых разрешениях.

## Важно

Сборки не подписаны. Полное удаление реальных продуктов и полная VM-матрица Windows/CSP требуют отдельной проверки перед стабильным релизом. Проект не связан с ООО «КРИПТО-ПРО».
