# КриптоПро Очистка 0.7.0

Modern для Windows 10/11 x64. [Публичное описание предварительного релиза и галерея](RELEASE_NOTES_0.7.0.md).

## Запуск

Распакуй Modern ZIP полностью и запусти `CryptoProCleanup.exe`. Все соседние файлы должны оставаться рядом. Установка .NET или отдельного WinUI runtime не требуется.

## Что изменилось

- Главная показывает три задачи: сохранить данные, удалить программы, проверить другой диск.
- Удаление вынесено на отдельную страницу. Выбор программ и папки копии ведёт к просмотру плана и подтверждению.
- Лицензии доступны прямо с главной. Выбор сертификатов находится в отдельном разделе.
- Новое оформление: сине-графитовые поверхности, бирюзовый акцент, крупные карточки действий и подписанная навигация.
- Светлая, тёмная и системная темы, RU/EN и изменение размера окна сохранены.
- Экспорт сертификатов закреплён внизу окна, отдельно от прокрутки списка. Исправлено обрезание нижней панели при 900×650.
- Во всех сценариях выбора каталогов Modern используется общий нативный диалог Windows. Он возвращает обычный путь без преобразования через WinRT StorageFolder.

## Данные

«Сохранить данные» создаёт копию полных лицензий и выбранных открытых сертификатов вместе с отчётами. Выбор сертификатов действует и при сохранении с главной. Экспорт CER/P7B не содержит закрытые ключи.

Штатная деинсталляция и очистка используют прежнее общее ядро. Изменения этой версии касаются оболочки и навигации. Legacy для Windows 7 не перерабатывался.

## Технологии

WinUI 3, XAML и C++17. Эта основа уже используется в проекте и даёт нативные элементы, доступность Windows и локальную работу с реестром без отдельного браузерного слоя.

При проектировании навигации использованы рекомендации Microsoft:

- [Navigation basics](https://learn.microsoft.com/en-us/windows/apps/design/basics/navigation-basics).
- [NavigationView](https://learn.microsoft.com/en-us/windows/apps/design/controls/navigationview).

## Проверка

Проверено на Windows 11 x64, сборка 26100:

- Release x64, модульные тесты и ресурсы тем/раскладки.
- Семь страниц, RU/EN, Dark/Light/System, переходы с главной; окна 900×650, 1024×760 и 1280×720.
- Реальное сохранение через интерфейс в тестовую папку внутри AppData: отмена и повторное открытие диалога, один выбранный сертификат, лицензии, JSON, текстовый отчёт, журнал и открытие страницы результатов.
- Безопасный интеграционный тест ядра: копирование и неизменность исходного инвентаря продуктов/сертификатов.
- После выделения общего выбора папки собран Win32 Legacy и пройдена его UI-проверка на малых разрешениях.

Публичная галерея снимается отдельно от приватных UI-артефактов:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\ui-smoke.ps1 -PublicGallery -ArtifactsDirectory docs\screenshots\0.7.0
```

Этот режим очищает поле резервного пути и скрывает личные сертификаты штатным поиском. Он не удаляет продукты и не экспортирует данные. Перед публикацией каждый снимок всё равно нужно просмотреть: имя профиля или данные другой машины могут отличаться. Обычные снимки UI smoke не предназначены для публикации.

Новая версия на Windows 10 отдельно не запускалась. Реальное удаление CryptoPro, аппаратные токены, отключённый физический диск и перезагрузка в рамках этой работы не проверялись. Предыдущие результаты их проверки не подменяют новый прогон.
