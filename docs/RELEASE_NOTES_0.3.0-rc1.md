# КриптоПро Очистка 0.3.0 RC1

Первый публичный релиз-кандидат portable-утилиты для резервного копирования лицензий и открытых сертификатов, штатного удаления продуктов CryptoPro с последующей подтверждённой очисткой и спасения данных из отключённой Windows.

## Главное

- полный номер лицензии можно показать, скопировать и сохранить отдельно;
- выбранные открытые сертификаты экспортируются в CER и P7B, закрытые ключи не экспортируются;
- на работающей Windows сначала запускается зарегистрированный MSI/EXE-деинсталлятор;
- остаточная очистка ограничена планом, построенным до удаления;
- отдельная вкладка читает отключённую Windows и сохраняет лицензии/сертификаты без изменений;
- офлайн-очистка требует резервной копии на другом диске и отдельного подтверждения;
- приложение не требует установки, .NET, PowerShell или интернета.

## Проверка загрузки

Сверьте SHA-256 скачанного архива со значением в описании GitHub Release. Внутри архива находится `SHA256SUMS.txt` для проверки отдельных файлов.

## Статус тестирования

Безопасное сканирование проверено на Windows 11 x64 с CryptoPro CSP 5.0 и браузерным плагином. Модульные тесты и статический анализ пройдены. Разрушительная VM-матрица Windows 7–11 и CSP 3.x/4.x/5.x ещё не завершена, поэтому это prerelease, а не стабильный выпуск.

## Важно

Проект не связан с ООО «КРИПТО-ПРО». EXE не подписан цифровой подписью; предупреждение SmartScreen ожидаемо. Перед удалением сохраните резервную копию вне системного диска.
