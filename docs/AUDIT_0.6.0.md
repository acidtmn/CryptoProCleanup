# Проверка 0.6.0-preview1

База: ff6d8dd. Только локальная разработка; публикация ожидает проверки автором.

## Найдено и исправлено

- Конфликт синхронизации исходной рабочей папки: создана отдельная копия актуального main вне Яндекс Диска. Старые изменения сохранены.
- Неподписанные значки компактной навигации: добавлены RU/EN подписи.
- Нет понятного следующего шага: закреплённая панель выбора программ, папки и просмотра плана.
- Резервная копия была связана с удалением: добавлен самостоятельный сценарий Modern с проверкой папки, общим gate операций и переходом к отчётам.
- Заголовок списка перекрывался счётчиком: раздельные колонки.
- Версия resume-помощника 0.5.3.0 была захардкожена: сравнение с CPC_VERSION_NUMERIC.
- UTF-8 описание Modern EXE читалось неверно в ресурсах: задан code_page(65001).
- В Legacy при малой высоте кнопка проверки плана перекрывала список: уплотнён заголовок и исправлены размеры строк действий. Добавлены проверки отсутствия пересечений при 768×528 и 640×480.

## Автоматические проверки

Проверено локально 11 сентября 2026 года:

- Release x64 (Modern + помощник) и Release Win32 (Legacy): успешная сборка MSVC v143, модульные тесты прошли в обеих архитектурах.
- Проверки XAML-ресурсов: 82 одинаковых ключа тем, 15 токенов раскладки, 7 семантических стилей карточек.
- Безопасный интеграционный прогон x64 и x86: найдены 2 продукта, 1 профиль, 7 открытых сертификатов; проверены экспорт CER/P7B, резервная копия без плана очистки, отсутствие полных лицензий в обычных отчётах, неизменность инвентаря продуктов и сертификатов после сохранения. Созданные тестовые копии удалены, исходные данные не удалялись.
- Modern UI: все шесть страниц, RU/EN, Dark/Light/System, 1024×760 и 1280×720, доступность флажков, видимость новых действий и закреплённой подсказки; снимки просмотрены локально.
- Legacy UI: 800×600, 1024×768, рабочая область 768×528; дополнительно главная при 640×480. Кнопки внутри окна, список и действия не перекрываются.
- `git diff --check`: без ошибок пробелов.
- Новые кнопки перехода с главной: проверено фактическое открытие страниц сертификатов и другого диска в активном окне. Системный выбор папки требует отдельной ручной проверки, см. ниже.

Снимки автоматизации остаются в локальной папке `artifacts` и не включаются в архив исходников: страницы сертификатов могут содержать персональные данные.

## Не проверено на этой машине

Системный диалог новой кнопки «Сохранить данные» открывается (подтверждено снимком), но его кнопку отмены не удалось надёжно обнаружить через UI Automation. Этот эксперимент не включён в успешный UI smoke. Выбор папки, завершение сохранения и отмену через графический интерфейс нужно проверить вручную; сам движок сохранения проверен интеграционным тестом.

Удаление реальных продуктов, запись в отключённую Windows, реальный RunOnce и перезагрузка, полная матрица Windows/CSP, OS-level High Contrast и отдельные DPI-сессии. Тесты не дают гарантии поведения стороннего штатного деинсталлятора.
